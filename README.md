# COP4331-colors-lab-daniel-evans
The colors lab is a web application that allows users to login and add/delete from a list of colors in a database.

Technologies used:
Ubuntu- Server hosted by DigitalOcean LAMP droplet.
MySQL- Database
PHP- Backend API endpoints
GoDaddy- Domain name hosting
PuTTY- SSH

High-level Setup Instructions:
1. Create the Ubuntu server and acquire domain name.
2. Connect to server through SSH client.
3. Set up database using MySQL.
4. Upload API files.

How to Run Application:
1. Connect to http://danielevanslabproject.com/
2. Login with user credentials.
3. Add or search for colors.

Assumptions:
This project is intended for small-scale, personal use.

Limitations:
Users have to registered using MySQL in an SSH client, there is no way to register on the web app.
